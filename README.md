# 🎵 Spotify-Inspired Music Player
A responsive, interactive web music player built with HTML, CSS, and JavaScript — inspired by Spotify's sleek design and smooth user experience.

# #🚀 Features:
Play, pause, skip, and select tracks

Dynamic playlist functionality

Real-time progress bar & track timer

Mobile-friendly and responsive design

Seamless UI transitions and animations

Event-driven JavaScript handling for user interactions

# #🛠️ Technologies Used:
HTML5 for structure

CSS3 for styling and responsiveness

JavaScript (ES6) for interactivity and logic

# #📚 Learnings & Highlights:
Practiced DOM manipulation and event handling in JavaScript

Designed a responsive UI using Flexbox and media queries

Enhanced performance with optimized asset loading

Validated features through manual testing for smooth user interaction
